# Index des illustrations OCTO (assets/illustrations/)

Fichiers dans `<SKILL_DIR>/assets/illustrations/` (PNG uniquement : python-pptx n'insère pas de SVG).
Palette de référence : #0E2356 marine, #00D2DD turquoise, blanc, teintes de marine (#DCE3F1, présent dans certains fichiers, est proche de `#E7E9EE` mais hors liste).
Couleurs mesurées par échantillonnage de pixels (approximation ±10 sur chaque canal : le PNG de `extraits-09`, dont le SVG est en #28C9DB, mesure #38B8D0).
Les illustrations d'origine en SVG sont fournies ici en PNG (même image).

Légende « conforme » : **oui** = palette stricte ; **proche** = teintes voisines hors charte (marine #0E284B au lieu de #0E2356, turquoise #28C9DB au lieu de #00D2DD) ; **non** = couleur étrangère à la charte.
